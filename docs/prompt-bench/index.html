Prompt Bench

システムプロンプト・ユーザープロンプト・パラメータを固定してN回繰り返し実行し、出力のばらつきを検証する

実行API設定（OpenAI互換）
APIキーはJS変数（メモリ上）にのみ保持し、ページを閉じると消去されます。localStorage等への保存は行いません。 ブラウザから直接APIへリクエストするため、Origin制限のあるプロバイダでは失敗する場合があります（実行時にCORSエラーの案内を表示します）。

各実行の結果 ⓘ各実行のバッジの意味:
・ms（先頭）: リクエスト開始から完了までの合計時間
・初回: ストリーミング有効時のみ。最初のトークンが届くまでの時間（レスポンス生成が始まった目安）
・prompt / completion / total: 入力（システム+ユーザープロンプト）のトークン数 / モデルが生成した出力のトークン数 / その合計
・キャッシュ: プロンプトキャッシュがヒットしたトークン数（対応プロバイダのみ）
・finish: 生成が止まった理由。stop=正常終了、length=max_tokens上限で打ち切り
・残TPM: プロバイダ申告の1分あたりトークン残数（対応プロバイダのみ）
